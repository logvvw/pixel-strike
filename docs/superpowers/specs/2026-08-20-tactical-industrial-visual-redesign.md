# PixStrike 战术工业风视觉重写设计

日期：2026-08-20

## 目标

把现有混杂的灰色场景、亮黄 HUD、绿色经济提示、emoji 图标和通用块状枪模，统一重写为“90 年代战术工业风”的像素视觉系统。新版需要保留清晰、克制、低饱和的 CS 气质，同时让场景、敌人、武器和界面属于同一个世界。

本阶段只重写现有单地图的视觉表现和界面，不新增地图、炸弹模式、联网玩法或外部素材依赖。

## 成功标准

- 游戏只使用一套明确的低饱和战术调色板，场景与 HUD 不再出现互相冲突的颜色。
- 墙壁、地面和天空具有可辨识的像素材质与空间层次，不再是大面积纯灰色。
- 材质图案锚定墙面或空间坐标，玩家转身时不会像屏幕滤镜一样漂移。
- 敌人的头部、躯干、装备和武器轮廓清晰，远距离仍能与墙面分离。
- Glock、MP9、AK-47 和 AWP 具有不同的枪身轮廓、比例和配色。
- HUD 遵循 CS 式信息层级：顶部回合信息，左下生命，右下弹药与金钱，准星保持视觉中心。
- 所有 emoji 被统一的 CSS/Canvas 像素图标或纯文字标签替代。
- 启动画面、购买菜单、回合消息、受伤效果和游戏内 HUD 使用同一套边框、间距、字体与状态色规则。
- 内部画布继续使用 320×200，桌面显示保持 960×600 的 3 倍整数缩放。
- 视觉重写后现有 30 项行为测试继续通过，浏览器启动与射击流程无控制台错误。

## 视觉方向

### 核心气质

关键词：战术、工业、旧军事终端、低饱和、粗粝、克制。

不使用霓虹渐变、卡通糖果色、圆角玻璃卡片、现代手游发光按钮或夸张 emoji。像素感来自有限调色板、硬边、网格与抖色，而不是简单降低分辨率。

### 调色板

场景基础色：

- `INK #11130F`：最深阴影、外框。
- `COAL #232721`：界面面板、深色金属。
- `GUNMETAL #3C4239`：枪械与工业墙面。
- `CONCRETE #777468`：水泥主色。
- `SAND #A69A7B`：沙岩与亮面。
- `DUST #C2B28C`：高光与远雾。
- `OLIVE #59604A`：军用设备与辅助区。
- `RUST #8A4F36`：锈蚀、受击与危险提示。

界面状态色：

- `AMBER #E3B341`：主要交互、计时器、当前武器。
- `IVORY #DDD8C4`：主文字、准星。
- `MUTED #858778`：次级文字。
- `SAFE #87A36F`：生命与购买成功。
- `DANGER #C65343`：低血量、空弹、伤害与击杀。

同一画面不同时使用超过一个主强调色。AMBER 是常态强调色，SAFE 和 DANGER 只表达状态。

## 空间与材质系统

### 天空和地面

- 天空使用从灰橄榄到尘灰的离散色带，并加入稀疏 2×2 像素抖色。
- 地面使用暗砂色透视带、低对比接缝和靠近玩家更明显的颗粒。
- 地平线通过轻微尘雾软化，但仍保持像素硬边，不使用连续模糊滤镜。
- 玩家视角后坐或上下移动时，天空、墙面、地面和敌人共用同一地平线偏移。

### 墙面材质

地图瓦片 1–4 保留现有语义，但重新定义视觉：

- 1：水泥砖墙。8×8 像素砖缝、轻微色差和边缘磨损。
- 2：旧木板。纵向木纹、暗钉与交错接缝。
- 3：红棕砖墙。规则砖缝、低饱和锈红与深色凹缝。
- 4：军绿金属板。分块接缝、铆钉和局部高光。

`Renderer.castRay` 返回墙面命中坐标 `wallX`。材质采样使用 `wallX` 和墙面纵向比例生成 16×16 程序化纹理，保证图案锚定墙面。距离雾和侧面阴影在纹理采样后统一应用。

瓦片 5–8 继续作为目标点和出生点语义，不渲染成实体墙。

### 场景标识

本阶段不增加新的地图几何。可以在目标点所在的地面区域绘制低对比 AMBER 标线，但不得阻碍战斗可读性。

## 角色视觉

敌人使用 16×24 的程序化 billboard 造型，不依赖图片素材：

- 头部：较亮的面罩或头盔高光，占精灵上方约 28%。
- 躯干：军绿或棕灰护甲，左右肩轮廓明显。
- 装备：深色胸挂、腰带和手臂阴影。
- 武器：从躯干侧面伸出的深色短轮廓。
- 腿部：分离成两条暗色像素柱，移动时可交替 1 像素形成步行动画。

受击时只短暂提高亮度并叠加 RUST，不使用纯白整块闪烁。爆头击杀可以产生少量向外飞散的 1–2 像素粒子，持续时间不超过 180 毫秒。

## 第一人称武器

不再共用一套通用方块枪模。每把武器由独立的矩形部件描述绘制：

- Glock-18：短枪管、紧凑套筒、棕黑握把，画面占用最小。
- MP9：短枪管、垂直弹匣、折叠枪托，整体靠近画面中心。
- AK-47：长枪管、弯曲弹匣、木质护木，水平轮廓最明显。
- AWP：长枪管、瞄准镜、军绿色枪托，纵向后坐幅度最大。

所有枪模共享：

- 炭黑手套与前臂，避免枪械悬浮。
- 同一方向的 1 像素高光与深色描边。
- 移动摇摆、射击后坐和换弹下沉。
- AMBER、IVORY、RUST 三色组成的短时枪口火焰。

枪械配色服从材质规则，不使用独立的鲜艳主题色。

## HUD 与界面

### 游戏内布局

- 顶部中央：`CT // WAVE 01 // HOSTILES 03` 风格的回合条，计时器位于右侧。
- 左下：十字像素图标、生命数值和短条，不使用爱心。
- 右下：当前武器、弹匣大数字、备弹小数字、金钱；弹匣为空时切换 DANGER。
- 左上：分数使用小号次级文字，不与回合信息争夺注意力。
- 击杀条：右上深色窄条，武器名和 HEAD 标签使用 AMBER/RUST。
- 准星：IVORY 四臂准星，动态散布只改变间距，不增加光晕。

所有 HUD 元素对齐 4 像素网格，使用 1 像素描边和硬阴影。正常状态不使用半透明大渐变；只有顶部和底部允许极轻的遮罩帮助文字阅读。

### 启动画面

启动页改成“任务终端”：

- 左上小号系统编号，中央 `PIXSTRIKE` 字标。
- 副标题改为 `TACTICAL SIMULATION // BUILD 01`。
- 主按钮改为方形 AMBER 描边的 `DEPLOY`。
- 操作说明拆成 2×3 的键位网格，使用 `WASD`、`MOUSE 1`、`R`、`B` 等标签。
- 背景加入低对比网格、地图坐标线和角落标记，不使用图像。

### 购买菜单

购买菜单改成“军械库终端”：

- 左侧武器分类和编号，右侧价格与拥有状态。
- 当前可购买项用 AMBER 左边线标记。
- 余额不足使用 MUTED，不再仅靠透明度表达。
- 不可购买项不绑定点击处理，避免视觉与行为不一致。

## 模块边界

### `js/ui/theme.js`

新增唯一视觉令牌来源，导出：

- `PALETTE`：RGB 数组与 CSS 十六进制值。
- `MATERIALS`：瓦片 1–4 的基础色、阴影色、高光色和纹理类型。
- `WEAPON_SKINS`：四把武器的部件颜色与轮廓参数。
- `UI_COPY`：统一的英文战术标签，避免字符串散落。

### `js/engine/renderer.js`

负责天空、地面、墙面材质、敌人、粒子和第一人称枪模。它只消费主题令牌与游戏状态，不定义 HUD DOM 样式。

### `js/ui/hud.js`

负责 DOM 状态、文本和 class 切换。状态色由 CSS class 表达，不在 JavaScript 中写入任意颜色值。

### `css/style.css`

负责启动页、HUD、购买菜单和覆盖层。顶部声明与 `theme.js` 对应的 CSS 自定义属性，后续样式只能引用这些变量。

### `index.html`

只定义语义结构和静态标签。移除 emoji 与内联视觉样式，不在 HTML 中写颜色、字体大小或间距。

## 数据流

1. `theme.js` 提供固定调色板、材质和武器皮肤。
2. Renderer 根据地图瓦片、射线命中坐标、距离和朝向采样材质。
3. Renderer 使用玩家状态、武器类型和反馈状态绘制敌人、粒子与枪模。
4. HUD 根据玩家、回合和反馈状态切换有限的语义 class。
5. CSS 使用视觉令牌把语义 class 映射为统一颜色、边框与动画。

任何模块都不得在运行时生成新的随机颜色。程序化纹理允许使用基于坐标的确定性噪声，禁止每帧 `Math.random()` 造成闪烁。

## 稳定性与性能

- 墙面纹理使用整数运算或小型查找函数，不在每像素循环中创建对象或数组。
- 武器部件和材质定义在模块加载时创建，渲染帧内只读取。
- 未知瓦片回退到水泥材质；未知武器回退到 Glock 轮廓。
- CSS 动画只改变 transform、opacity 或颜色，不触发布局抖动。
- 保持内部画布 320×200，不增加离屏高分辨率渲染。
- 所有短时 UI 计时器继续清理或覆盖旧计时器，防止新消息被旧回调隐藏。

## 测试与验收

自动化测试新增：

- 主题令牌包含必需颜色、四种材质和四把武器皮肤。
- 同一墙面坐标始终返回相同纹理颜色。
- 四种墙面材质返回不同的可见颜色组合。
- 瓦片 5–8 不会被材质系统判定为墙。
- 四把武器的轮廓部件数量和边界合法。
- HUD 状态映射不产生未定义 class。

浏览器验收：

- 1280×720 下画布为 960×600，像素边缘清晰。
- 启动页、购买菜单、游戏内 HUD 和死亡覆盖层视觉一致。
- 四类墙面、敌人和枪械在常规战斗距离可快速辨认。
- 受伤、命中、爆头、击杀和低弹药反馈遵循统一状态色。
- 启动、移动、射击、换弹、购买、死亡和重启没有控制台错误或缺失资源。
- 保存桌面与窄屏截图，检查文字溢出、重叠和非整数缩放造成的模糊。

## 非目标

- 不制作或下载外部贴图、字体、声音和精灵图。
- 不增加动态光源、阴影贴图、WebGL 或后处理框架。
- 不重新设计地图布局或增加地图选择器。
- 不改变武器伤害、敌人 AI、经济数值和回合规则。
- 不追求对任何 CS 具体地图或 UI 的逐像素复制。
